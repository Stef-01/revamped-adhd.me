Automated decisions

Last updated 26 September 2026

This statement explains how ADHDme uses automation, in line with the Privacy Act’s transparency rules for automated decisions, which start on 10 December 2026. We don’t use personal information to make decisions about you.

1. What is automated

Some parts of the site run automatically, but none of them decide anything about you:

  • The clinician directory is shown in the same order to everyone. It isn’t ranked or personalised.
  • The Care Navigator shows the clinicians whose profiles say they work on the area you choose. Everyone who makes the same choice sees the same clinicians.
  • Booking links carry a tag so the practice can see the visit came from ADHDme.
  • Analytics counts visits and clicks so we can see how the site is used. Our privacy policy explains what is collected.

2. What is never automated

We never use automation to:

  • make clinical decisions, such as diagnosis, triage or assessing symptoms
  • decide whether you can get care
  • rank or prioritise people

3. Human oversight

A person maintains the clinician listings and reads every email sent to info@adhdme.au. Clinicians can ask us to correct or remove their listing at any time. We update this statement whenever the way the site works changes.
