How handoffs are counted

The last thing this site can honestly observe is somebody leaving for a practice's booking page. This page says how that is counted, where each count can be read, and what cannot be seen from here.

The channels

  • The practice's own reporting. Live. Every booking link carries a source tail (utm_source=adhd-me, utm_medium=referral, utm_campaign=<surface>) into Healthengine, so the practice can see referrals from their side. Read it in the practice's Healthengine reporting, source "adhd-me".
  • Analytics events. Not switched on. The site declares a closed set of events (below) and sends them only when an analytics ID is configured in analytics-config.js. Until then every event is validated and dropped, and no request leaves the page. When it is switched on, page visits are counted without cookies and with advertising signals disabled, and the privacy policy is updated the same day.
  • This device's tally. Live, local. Each handoff is appended to a small log in this browser's own storage: clinician, surface and day. Nothing identifying, and it never leaves the device.
  • Whether a booking followed. Cannot be observed from here. Healthengine has no conversion endpoint for a third party. Nothing on this site claims a booking it cannot see.

The events this site declares

  • landing-viewed: somebody arrived at the front door.
  • landing-cta: which of five named controls was pressed (hero-cta, nav-cta, nav-doctors, nav-learn, nav-approach).
  • deck-viewed: somebody opened The Doctors, with how many GPs the deck held.
  • profile-viewed: somebody opened one GP's page, and from which surface.
  • booking-outbound: somebody left for the practice's booking page, which GP and from which surface.

Every event is checked against this list before it is sent. An event outside it, or a property outside its declared vocabulary, is refused and logged as analytics-refused rather than becoming a row that looks real.

How to read the funnel

Landing → deck is whether one screen and one button are enough to make somebody look at the doctors. Deck → profile is whether the cards say enough about a person to be worth opening. Profile → handoff is whether the page answers what somebody needs before they act. None is a conversion rate: the last step is a handoff, and whether an appointment happened is not observable from here. Somebody who arrives, reads the one sentence and decides this is not for them has been served, not lost.
